# Sports Analytics Capstone

Live site: https://arpitvats13.github.io/sports-analytics-capstone/

An end-to-end data science project built during the YuvaIntern Virtual Data Science with Python internship (July 6 to August 10, 2026). It covers data cleaning, visual storytelling, hypothesis testing, injury-risk prediction with machine learning, and an integrated summary.

## What is inside

- index.html: the project site, including a live injury-risk predictor
- code/: five Python scripts, one per internship week

## About the data

All data is synthetic. It is generated in Python with NumPy (random seed 42), so the findings demonstrate the method and do not describe real players.

## How to run the code

    pip install pandas numpy scipy scikit-learn matplotlib seaborn
    python code/week5_integrated_pipeline.py
